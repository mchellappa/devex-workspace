# .NET Core Templates

This directory contains Handlebars templates for generating .NET Core 9.0 (latest LTS) projects.

## Templates

### Project Files
- **Program.cs.template**: Minimal API entry point (.NET 9.0 style)
- **.csproj.template**: Project file with package references
- **appsettings.json.template**: Application configuration
- **appsettings.Development.json.template**: Development configuration

### API Layer
- **Controller.cs.template**: API Controllers with attributes
- **MinimalApi.cs.template**: Minimal API endpoints (.NET 9.0 style)

### Service Layer
- **Service.cs.template**: Business logic services
- **IService.cs.template**: Service interfaces

### Data Layer
- **Repository.cs.template**: Generic repository pattern
- **IRepository.cs.template**: Repository interface
- **DbContext.cs.template**: Entity Framework DbContext
- **Entity.cs.template**: Domain entities

### DTOs
- **RequestDto.cs.template**: Request DTOs with validation
- **ResponseDto.cs.template**: Response DTOs

### Middleware & Filters
- **GlobalExceptionHandler.cs.template**: Global exception handling
- **ValidationFilter.cs.template**: Model validation filter

### Security
- **JwtAuthenticationHandler.cs.template**: JWT authentication
- **AuthorizationPolicies.cs.template**: Authorization policies

### Configuration
- **DependencyInjection.cs.template**: Service registration
- **SwaggerConfig.cs.template**: Swagger/OpenAPI configuration
